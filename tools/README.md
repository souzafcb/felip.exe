# Ferramentas

- `build_fez_documents.py`: gera as versões DOCX diagramadas a partir dos PDFs originais.
- `build_fez_site.py`: recompõe o HTML usando o conteúdo editorial estruturado.
- `validate_fez_outputs.py`: confere presença de conteúdo e pontos editoriais essenciais.
- `inspect_pdf_layout.py`: inspeciona tipografia e posicionamento nos PDFs de origem.
- `make_contact_sheets.py`: monta folhas de contato a partir de páginas renderizadas em `work/render_separate/`.

Os materiais temporários de renderização não fazem parte do repositório.
